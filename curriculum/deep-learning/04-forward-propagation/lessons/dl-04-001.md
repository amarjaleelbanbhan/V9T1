# Dense layer shapes


## Vocabulary

- **Batch size**: Number of examples processed together.

- **Input width**: Number of features per example.

- **Output width**: Number of output features.


## Meaning

Using the row-vector convention, X has shape (B,D), W has shape (D,H), and Y = XW + b has shape (B,H). A bias of shape (H,) broadcasts across B examples. The shared inner D dimensions contract. The panel counts output elements; zero cells are shape placeholders, not computed predictions.


## Purpose

Writing shapes first catches incompatible layers early.


## Calculation

(B,D) @ (D,H) -> (B,H)


### Worked case

Inputs: [2, 3, 4]. Result: 8. Intermediate operations are available in the app.


### Transfer case

Inputs: [3, 4, 2]. Result: 6. Intermediate operations are available in the app.


## Explain

Which dimensions must match for XW?

The input width D of X and first axis of W

The inner dimensions contract in matrix multiplication.


## Debug

Using a transposed weight convention without updating the equation.

Some libraries store W as (H,D); their forward operation uses its transpose.
