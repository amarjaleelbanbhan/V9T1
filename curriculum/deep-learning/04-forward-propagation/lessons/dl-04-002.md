# Batch axis


## Vocabulary

- **Batch axis**: The axis distinguishing examples.

- **Feature axis**: The axis distinguishing values within an example.


## Meaning

Increasing batch size adds examples, not features or new model parameters. A batch of three rows with four features can feed the same weights as a batch of one row with four features. The output preserves the batch axis. Aggregate losses deliberately over examples; do not accidentally mix batch and feature reductions.


## Purpose

Batch semantics determine how predictions and gradients are averaged.

## Explain

Does a larger batch automatically add model weights?

No; examples share the same layer parameters

A layer reuses its weight matrix for every row.
