# Layer composition


## Vocabulary

- **Hidden value**: An intermediate representation between input and output.

- **Composition**: Feeding one operation result into the next.


## Meaning

This small network computes hidden = ReLU(w₁x + b₁), then output = w₂hidden + b₂. With x = 2, w₁ = 3, b₁ = -1, hidden = 5. With w₂ = 2 and b₂ = 1, output = 11. An inactive hidden ReLU makes its input-dependent contribution zero.


## Purpose

Following intermediate values explains the final prediction.


## Calculation

output = w₂ ReLU(w₁x + b₁) + b₂


### Worked case

Inputs: [2, 3, -1, 2, 1]. Result: 11. Intermediate operations are available in the app.


### Transfer case

Inputs: [-1, 3, -1, 2, 1]. Result: 1. Intermediate operations are available in the app.


## Explain

When hidden ReLU is zero, what remains at this output?

The output bias b₂

The weighted hidden term is zero, leaving the output offset.
