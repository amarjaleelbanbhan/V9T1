# Matrix multiplication


## Vocabulary

- **Row-column product**: A dot product defining one matrix output.

- **Inner dimension**: The matched dimension summed over.


## Meaning

For A = [[1,2],[3,4]] and B = [[1,2],[3,4]], A@B is [[7,10],[15,22]]. The bottom-right result is 3×2 + 4×4 = 22. Elementwise multiplication would produce [[1,4],[9,16]], a different operation. The panel uses editable A and fixed B.


## Purpose

Dense layers compute many weighted sums with matrix multiplication.


## Calculation

C[i,j] = Σ A[i,k]B[k,j]


### Worked case

Inputs: [1, 2, 3, 4]. Result: 22. Intermediate operations are available in the app.


### Transfer case

Inputs: [2, 0, 1, -1]. Result: -2. Intermediate operations are available in the app.


## Explain

Is matrix multiplication the same as multiplying matching entries?

No; each output combines a row and a column

The sum over the inner axis distinguishes matrix multiplication.


## Debug

Multiplying row i by row j rather than column j.

For bottom-right output, select A row one and B column one with zero-based indexing.
