# Confusion matrix, precision, recall and F1


## Vocabulary

- **TP**: A positive case correctly predicted positive.

- **FP**: A negative case incorrectly predicted positive.

- **FN**: A positive case incorrectly predicted negative.

- **F1**: Harmonic balance of precision and recall.


## Meaning

Precision asks how many predicted positives are correct: TP/(TP+FP). Recall asks how many actual positives are found: TP/(TP+FN). F1 = 2TP/(2TP+FP+FN). For TP = 3, FP = 1, FN = 2, precision is 0.75, recall is 0.6 and F1 is 2/3. Undefined zero denominators must be reported explicitly.


## Purpose

Different errors have different costs; accuracy alone can hide them.


## Calculation

F1 = 2TP/(2TP + FP + FN)

### Transfer case

## Explain

What is the denominator of recall?

All actual positives: TP + FN

False negatives are missed actual positives. False positives belong to precision.


## Debug

Swapping precision and recall denominators.

For TP = 0, FP = 0, FN = 2, precision is undefined while recall is zero.
