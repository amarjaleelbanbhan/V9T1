# Symbolic versus learned systems


## Vocabulary

- **Rule**: Behavior explicitly written by a programmer.

- **Parameter**: An adjustable value in a model.

- **Learning**: Using data to choose parameters.


## Meaning

A rule-based system applies specified logic. A learned system adjusts parameters from examples. Both can be AI. Fit a line through two observed input-target pairs: slope is target difference divided by input difference. This fitting is a tiny learning example; good training accuracy alone does not prove future accuracy.


## Purpose

The distinction helps you choose a transparent rule or a data-driven model for a problem.


## Calculation

learned slope = (y₂ - y₁)/(x₂ - x₁)
