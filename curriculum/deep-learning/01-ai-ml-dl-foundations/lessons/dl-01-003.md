# Features, labels and predictions


## Vocabulary

- **Feature**: Input information available when making a prediction.

- **Label**: The observed target used to learn or evaluate.

- **Prediction**: A model output for an input.


## Meaning

If hours studied is a feature and exam score is the label, a toy model might predict score = 10 × hours + 20. A prediction can be wrong even if its calculation is correct. Inputs must be available at prediction time; including the final score as an input leaks the answer.


## Purpose

Keeping these roles separate prevents meaningless evaluations.


## Calculation

prediction = weight × feature + bias


### Worked case

Inputs: [2, 10, 20]. Result: 40. The app exposes intermediate operations step by step.


### Transfer case

Inputs: [3, 10, 20]. Result: 50. The app exposes intermediate operations step by step.


## Explain

Can the final exam score be an input when predicting that same score before the exam?

No; it is unavailable and leaks the target

Future or target information cannot support the intended prediction task.


## Debug

Confusing the observed label with the predicted value.

If the label is 45 and prediction is 40, the signed prediction error is -5.
