# Leakage and split strategies


## Vocabulary

- **Leakage**: Using information unavailable for the intended prediction.

- **Group split**: Keep related observations in one subset.

- **Time split**: Evaluate future observations after earlier training.


## Meaning

Learn transformations using only training data. Apply the same learned transformation to validation and test. For training values 1 and 3, the mean is 2. Centering a held-out value 100 gives 98. Including that test value in the mean changes training decisions. Rows from one person or future observations require appropriate group or time splits.


## Purpose

Leakage can make a weak model appear strong.


## Calculation

centered test = test value - training mean

## Explain

Which mean is allowed for preprocessing the held-out test?
