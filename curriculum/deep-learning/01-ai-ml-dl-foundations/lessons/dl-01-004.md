# Training, validation and test sets


## Vocabulary

- **Training set**: Examples used to fit parameters.

- **Validation set**: Examples used to select settings.

- **Test set**: Held-out examples for final evaluation.


## Meaning

Fit weights on training data. Compare learning rates or thresholds on validation data. After choices are fixed, evaluate the test set. Repeatedly choosing settings on test performance turns the test set into validation data. Split sizes add up, but the roles matter more than a particular percentage.


## Purpose

Separate evaluation estimates how a chosen model performs on unseen data.


## Calculation

total = training count + validation count + test count

## Explain

Where should you choose a decision threshold?

On validation data before final testing

Repeated test-based decisions consume its independence.


## Debug

Training on all data and reporting the same-data score as held-out performance.

A total of 100 rows can have many legitimate split ratios. Explain the roles of all three subsets.
