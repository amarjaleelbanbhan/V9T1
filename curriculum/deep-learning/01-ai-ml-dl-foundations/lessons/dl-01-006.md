# Regression and classification


## Vocabulary

- **Regression**: Predict a numerical quantity.

- **Classification**: Predict a category.

- **Threshold**: A boundary converting a score into a decision.


## Meaning

Predicting a price is regression. Predicting whether a message is spam is classification. A binary score becomes class 1 when score ≥ threshold in this demonstration. Changing the threshold changes decisions, not the underlying score. A probability is between zero and one; an arbitrary raw score need not be.


## Purpose

The task type determines output interpretation and suitable evaluation.


## Calculation

class = 1 if score ≥ threshold, otherwise 0

Inputs: [0.6, 0.5]. Result: 1. The app exposes intermediate operations step by step.

## Explain

Does changing the threshold retrain this fixed-score model?

No; it changes the decision rule

Scores are held fixed here. Threshold selection and parameter fitting are separate.
