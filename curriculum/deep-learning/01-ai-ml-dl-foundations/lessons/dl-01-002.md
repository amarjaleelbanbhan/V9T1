# Supervised, unsupervised and reinforcement learning


## Vocabulary

- **Supervised**: Learn from input-target examples.

- **Unsupervised**: Find structure without task target labels.

- **Reinforcement**: Learn behavior using rewards from interactions.


## Meaning

Predicting a labeled price is supervised learning. Grouping similar unlabeled observations is unsupervised. Choosing actions from rewards is reinforcement learning. The sign-group demonstration is a deliberately specified grouping rule, not a trained clustering model. Count the groups present, and distinguish the demonstration from the learning categories.


## Purpose

The feedback available determines the type of learning problem.
