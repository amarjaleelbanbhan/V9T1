# Automatic differentiation


## Vocabulary

- **Forward pass**: Compute values using current parameters.

- **Reverse pass**: Apply local derivative rules in reverse order.

- **Accumulation**: Add contributions when variables are reused.


## Meaning

For y = s×x², reverse differentiation starts with dy/dy = 1, passes sensitivity s to x², then adds the two x multiplication paths. This is an exact derivative of the executed numerical operations, subject to floating-point effects. Finite differences instead approximate sensitivity by perturbing inputs. Framework gradients may accumulate across backward calls unless explicitly cleared.


## Purpose

Autodiff makes large computation graphs trainable without deriving every full formula by hand.


## Calculation

dy/dx = sx + sx
