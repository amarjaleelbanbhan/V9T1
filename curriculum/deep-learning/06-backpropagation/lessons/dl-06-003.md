# Output and hidden deltas


## Vocabulary

- **Delta**: Loss sensitivity to a layer preactivation.

- **Hidden delta**: Sensitivity transmitted through downstream weights and the activation derivative.


## Meaning

Use one hidden ReLU and a linear output with half squared loss. Output delta is prediction - target. Hidden delta multiplies output delta by the output weight and the hidden ReLU derivative. At a negative hidden preactivation the derivative is zero, blocking this path. At exactly zero this model uses a zero subgradient.


## Purpose

Deltas separate error propagation from parameter-gradient calculation.


## Calculation

δ_hidden = δ_output × w_output × ReLU′(z_hidden)

Inputs: [2, 1, 0, 3, 1, 4]. Result: 9. Intermediate operations are available in the app.


### Transfer case
