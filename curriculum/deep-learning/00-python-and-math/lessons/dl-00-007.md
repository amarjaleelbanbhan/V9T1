# Vectors, matrices and dot products


## Vocabulary

- **Vector**: An ordered list of coordinates.

- **Matrix**: Numbers arranged along rows and columns.

- **Dot product**: Sum of products of corresponding coordinates.


## Meaning

Pair each input with the weight at the same position. Multiply each pair, then sum. For x = [2,3] and w = [4,-1], products are 8 and -3, giving 5. A dot product requires equal lengths. Matrix multiplication repeats compatible dot products; it is different from multiplying elements at matching positions.


## Purpose

Neurons and dense layers calculate weighted sums with dot products.


## Calculation

x · w = x₁w₁ + x₂w₂

## Explain

What must match for a vector dot product?

The two vector lengths

Lengths define how many coordinate pairs exist; values may differ.


## Debug

Using Python list concatenation instead of numeric addition.

[2,3] + [4,-1] concatenates lists in Python. It does not calculate a dot product.
