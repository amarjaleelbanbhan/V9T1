# Loading and cleaning data


## Vocabulary

- **Row**: One observation in a table.

- **Missing value**: A field with no observed value.

- **Duplicate**: A repeated record under a chosen identity rule.


## Meaning

Inspect a loaded table before modeling: columns, types, missing values and units. In this toy table we drop a missing measurement and one exact duplicate, then calculate the mean. Real cleaning needs domain knowledge: repeated measurements may be legitimate, and removing missing rows can bias a sample. Fit any learned imputation rule using training data only.


## Purpose

Silent data errors can make a correct learning algorithm solve the wrong problem.


## Calculation

cleaned mean = sum of retained unique values / retained count
