# Computers and programs


## Vocabulary

- **Program**: Ordered instructions processed by a computer.

- **Input**: Values supplied before processing.

- **Output**: Values produced by those instructions.


## Meaning

A processor follows instructions; it does not infer the meaning you intended. Read x, multiply by a factor, then add an offset. Changing the order generally changes the answer. The lesson executes Python in a downloaded runtime; the browser displays its recorded values.


## Purpose

Tracing one instruction at a time lets you locate where a wrong result began.


## Calculation

output = x × factor + offset


### Worked case

Inputs: [2, 3, 1]. Result: 7. The app exposes intermediate operations step by step.


### Transfer case

Inputs: [-2, 4, 1]. Result: -7. The app exposes intermediate operations step by step.


## Explain

Which operation happens first in this program?

Multiplication, followed by offset addition

The program explicitly specifies multiplication before addition. Parentheses and program structure determine order.


## Debug

Treating a program as a live formula instead of a sequence.

Predict the result if the offset is added before multiplication: (2 + 1) × 3 = 9. Explain the difference.
