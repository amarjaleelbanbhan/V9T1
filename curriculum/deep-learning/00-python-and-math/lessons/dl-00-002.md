# Variables, loops, functions and objects


## Vocabulary

- **Variable**: A name bound to a value.

- **Loop**: Instructions repeated for each item.

- **Function**: A reusable procedure with parameters and a returned value.

- **Object**: An instance whose attributes retain state.


## Meaning

Assignment stores a result when its line runs. A for loop visits list items in order. An if condition can skip an addition. Functions have call-local names; returning a value does not make a local name global. Methods update the attributes of a particular object. Use the real Python labs to inspect those scopes.


## Purpose

These operations turn mathematical recipes into reusable programs.
