# CPU, RAM, GPU and storage


## Vocabulary

- **CPU**: Executes general instructions.

- **RAM**: Working memory holding active data.

- **GPU**: A processor suited to many parallel operations.

- **Storage**: Persistent data such as files and checkpoints.


## Meaning

A saved file lives in storage. Loading it places data in RAM. A CPU or GPU performs computations on accessible data. Moving data to a GPU has a cost; parallel hardware does not automatically accelerate a small operation. The payload of an array is its element count times bytes per element, distinct from object and runtime overhead.


## Purpose

Memory estimates help you select batch sizes without mistaking disk space for RAM.


## Calculation

payload bytes = rows × columns × bytes per element

## Explain

Does this payload estimate include the entire Python runtime?

No; it counts only numeric element storage

Object metadata, allocator behavior, code, and runtime memory are additional.
