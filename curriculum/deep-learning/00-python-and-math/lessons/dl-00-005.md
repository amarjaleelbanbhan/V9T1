# Algebra and graphs


## Vocabulary

- **Slope**: Change in y per unit change in x.

- **Intercept**: y when x equals zero.

- **Graph**: Pairs of x and y drawn on axes.


## Meaning

A line y = mx + b combines a scaled input with an offset. With m = 3 and b = 1, x = 2 gives y = 7. Negative x follows exactly the same operations. Raising b shifts the line vertically; changing m alters its steepness. Read the axes rather than assuming every rising line has slope one.


## Purpose

Linear models and neural layers repeatedly use this operation.


## Calculation

y = m × x + b


### Worked case

Inputs: [2, 3, 1]. Result: 7. The app exposes intermediate operations step by step.


### Transfer case

Inputs: [-2, 3, 1]. Result: -5. The app exposes intermediate operations step by step.


## Explain

What changes when only b increases?

The line shifts vertically while slope stays fixed

The added offset changes every y by the same amount.


## Debug

Confusing slope with the height at one point.

Compare y = 3x + 1 and y = 3x + 2 at x = 0 and x = 2. The difference is always one.
