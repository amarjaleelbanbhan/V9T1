# Autograd graphs


## Vocabulary

- **Graph node**: An operation or value in a computation.

- **Gradient path**: A route from a parameter to the loss.


## Meaning

For y = s × x × x, x appears on two multiplication inputs. Each route contributes to the derivative, so dy/dx = sx + sx = 2sx. Automatic differentiation records operations and applies their local derivative rules. It is not the same as perturbing parameters or generating a symbolic formula for every possible program.


## Purpose

Shared parameters require adding contributions from every use.


## Calculation

dy/dx = s × x + s × x


### Worked case

Inputs: [2, 3]. Result: 12. Intermediate operations are available in the app.


### Transfer case

## Debug

Forgetting one occurrence of a reused variable.

Treating x×x as if only one operand depended on x gives half the correct derivative.
