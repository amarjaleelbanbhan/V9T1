# float16, float32 and float64


## Vocabulary

- **Precision**: How finely a format distinguishes representable values.

- **Rounding**: Choosing a nearby representable number.

- **Range**: Magnitudes a format can represent.


## Meaning

Finite precision means some nearby integers or decimals become the same stored value. This panel runs NumPy conversions to float16, float32 or float64 in Python, using ties to even. float16 has fewer fraction bits and a smaller range; float32 balances memory and precision; float64 is useful for sensitive numerical checks. More bits increase payload but do not fix every algorithmic error.


## Purpose

Rounding affects small updates, loss stability and gradient checks.
