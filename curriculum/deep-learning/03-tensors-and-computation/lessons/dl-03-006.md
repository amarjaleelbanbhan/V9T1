# Device placement


## Vocabulary

- **Device**: The processor/memory location used by a tensor.

- **Transfer**: Moving data between devices.


## Meaning

CPU and GPU tensors generally cannot participate in the same operation without a compatible transfer. Move both model and data to the intended device. A transfer can dominate a tiny computation, so GPU is not automatically faster. Our device labels illustrate compatibility; they do not allocate real GPU tensors.


## Purpose

Device mismatches cause runtime failures even when dimensions are correct.


## Calculation

compatible = one if both operands are on the same device


### Worked case

Inputs: [0, 1]. Result: 0. Intermediate operations are available in the app.


### Transfer case
