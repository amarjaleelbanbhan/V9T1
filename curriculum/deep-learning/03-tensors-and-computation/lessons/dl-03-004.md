# Memory layout and views


## Vocabulary

- **View**: A different interpretation of shared array memory.

- **Copy**: Separate element storage.

- **Alias**: Another reference to the same underlying object or memory.


## Meaning

A view can share data, so modifying it can modify the original array. A copy separates storage. Our panel uses a Python list alias to illustrate shared mutation of [1,2,3]; it does not claim to implement NumPy strides. In NumPy, basic slicing usually returns views while advanced indexing returns copies. Shape changes alone do not guarantee a copy.


## Purpose

Unexpected shared mutation can corrupt inputs or cached intermediate values.


## Calculation

write through alias; then sum original

## Explain

Does modifying a copy necessarily modify the original?

No; copies have separate element storage

The distinction depends on memory sharing, not merely variable names.
