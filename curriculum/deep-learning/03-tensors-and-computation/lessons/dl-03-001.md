# Shape, rank and dtype


## Vocabulary

- **Shape**: Lengths of the array axes.

- **Rank**: Number of axes, not matrix algebra rank here.

- **Dtype**: Representation used for each element.


## Meaning

Shape (2,3) means two rows of three values. Tensor rank is two because there are two axes; there are six elements. float32 uses four payload bytes per element, giving 24 bytes. A vector of length 100 has tensor rank one. Scalar shape () has rank zero.


## Purpose

Correct shape and dtype reasoning prevents errors before a layer runs.


## Calculation

payload = rows × columns × bytes per element


### Worked case

Inputs: [2, 3, 4]. Result: 24. Intermediate operations are available in the app.


### Transfer case

Inputs: [4, 3, 8]. Result: 96. Intermediate operations are available in the app.


## Explain

What is the tensor rank of shape (4,3)?

Two

Rank counts axes; twelve is the element count.


## Debug

Confusing element count, tensor rank and matrix linear-algebra rank.

A 2×3 matrix can have matrix rank at most two, but its tensor rank is always two.
