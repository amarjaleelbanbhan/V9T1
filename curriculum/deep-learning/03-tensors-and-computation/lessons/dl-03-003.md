# Indexing and slicing


## Vocabulary

- **Index**: An axis position, starting at zero.

- **Slice**: A selected range with an exclusive stop.


## Meaning

For [10,20,30,40], slice [1:3] selects 20 and 30. It includes index one and excludes index three. Indexing may remove an axis; slicing usually retains it. Negative indices count from the end in Python, though this teaching control uses nonnegative bounds.


## Purpose

Precise selection is necessary for batches, features and image crops.


## Calculation

selected sum = sum(values[start:stop])


### Worked case

Inputs: [1, 3]. Result: 50. Intermediate operations are available in the app.


### Transfer case

Inputs: [0, 2]. Result: 30. Intermediate operations are available in the app.


## Explain

Is the stop index included in a Python slice?

No; the stop is exclusive

An exclusive stop makes adjacent slices line up without overlapping endpoints.


## Debug

Expecting [1:3] to contain three items.

Its length is stop - start = 2 for this unit-step slice.
