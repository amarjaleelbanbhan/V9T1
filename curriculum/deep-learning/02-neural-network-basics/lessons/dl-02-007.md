# Initialization


## Vocabulary

- **Fan-in**: Number of incoming connections.

- **Symmetry**: Units behaving identically because their parameters match.

- **He scale**: A variance-based choice commonly used with ReLU.


## Meaning

Identical zero weights in a hidden layer can make units receive identical updates, preventing useful specialization. Random initialization breaks symmetry. He normal initialization uses variance 2/fan-in, hence standard deviation sqrt(2/fan-in), under its assumptions. The panel calculates the scale, not a random sample. One initializer is not suitable for every activation.


## Purpose

Appropriate scale helps prevent unstable signals and gradients.


## Calculation

He standard deviation = sqrt(2/fan-in)
