# Perceptron and XOR


## Vocabulary

- **Perceptron**: A weighted sum followed by a threshold.

- **Linear boundary**: A straight separating line in two dimensions.

- **XOR**: One if exactly one binary input is one.


## Meaning

For XOR, targets for (0,0),(0,1),(1,0),(1,1) are 0,1,1,0. A single linear threshold cannot separate the two positive corners from both negatives. Inspect all four predictions. Changing bias can improve one corner while worsening another; hidden nonlinear units can solve the problem.


## Purpose

This limitation motivates multilayer networks.
