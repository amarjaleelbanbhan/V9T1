# Weights and biases


## Vocabulary

- **Weight**: Scales one input contribution.

- **Bias**: An additive offset independent of the input.


## Meaning

Multiply each input by its corresponding weight, sum, then add the bias once. A negative weight reverses the sign of its contribution. Bias can shift a decision boundary even when inputs are zero. Changing a weight has no effect when its input is zero.


## Purpose

Weights express sensitivity to inputs; bias sets a baseline.


## Calculation

z = x₁w₁ + x₂w₂ + b

Inputs: [2, 3, 1, -1, 2]. Result: 7. Intermediate operations are available in the app.
