# Biological analogy limitations


## Vocabulary

- **Artificial neuron**: A numerical weighted sum and activation.

- **Biological neuron**: A living cell with much richer dynamics.


## Meaning

The neuron analogy motivates connected units but does not make a network a literal brain. Our unit calculates z = wx + b. Real biological neurons involve temporal signals, chemistry and many mechanisms absent here. Name the numerical operation precisely instead of claiming human-like understanding from a diagram.


## Purpose

A precise model is easier to reason about than an exaggerated analogy.
