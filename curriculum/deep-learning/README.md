# NeuralLab Deep Learning knowledge base

Start with [master curriculum](MASTER_CURRICULUM.md), [sources](SOURCE_CATALOG.md), [paths](LEARNING_PATHS.md), [coverage](COVERAGE_MATRIX.md) and [open work](RESEARCH_GAPS.md).

`catalog.json` is the canonical machine-readable catalog. It feeds the website browser through Vite JSON import; chapter documents are bundled as text with import.meta.glob. Stable chapter/lesson IDs are distinct from legacy lab route IDs. Status `specified` describes actionable lesson specifications; it never means the full chapter is taught in the app.

Every chapter contains an original numerical example, executable small Python reference, practice solution, mistake, visualization requirements and project. This first pass does not constitute a fully authored zero-to-advanced course. No upstream courses or datasets have been copied.
