# NeuralLab learning knowledge base

Start with [master curriculum](MASTER_CURRICULUM.md), [sources](SOURCE_CATALOG.md), [paths](LEARNING_PATHS.md), [coverage](COVERAGE_MATRIX.md) and [research gaps](RESEARCH_GAPS.md).

The catalog feeds the app library. Chapters 00–07 have 60 authored core lessons in the beginner course, linked lesson documents, visual calculations and worked/transfer checks. The Python labs execute trusted fixed examples; the training capstone performs actual JavaScript optimization. Eight mixed reviews supplement guided practice. Chapters 08–18 remain specified.

Implementation status is separate from learner evidence. Topic and review evidence is browser-local; mini-projects are self-reviewed. No claim of retained mastery or measured 90% visual effectiveness is made. All teaching explanations, examples, simulations and synthetic data are original; external material is linked rather than imported.
