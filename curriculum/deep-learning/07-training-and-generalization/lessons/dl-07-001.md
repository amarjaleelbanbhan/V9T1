# Dataset loaders and training loops


## Vocabulary

- **Dataset**: A collection exposing examples and targets.

- **Loader**: A mechanism assembling batches.

- **Training loop**: Repeated forward, loss, gradient and update operations.


## Meaning

For each batch: read features and targets, compute predictions, calculate loss, clear stale gradients, compute current gradients, then update parameters. Evaluation uses held-out data without fitting to it. A loader chooses batching and ordering; it does not automatically perform training. The final partial-batch policy is explicit in this count example.


## Purpose

A correct loop connects the mathematics to reproducible computation.


## Calculation

updates per epoch = ceil(example count / batch size)
