# Batching and shuffling


## Vocabulary

- **Shuffle**: Reorder examples before forming batches.

- **Seed**: A control making a pseudorandom order reproducible.


## Meaning

Shuffling changes which examples appear together and in what order, while preserving each example-target pairing. In ordinary epoch-based training, every training example should be visited according to the loader policy. The batch count is unchanged by reordering. Never shuffle inputs independently of their labels. Evaluation usually does not need shuffled order.


## Purpose

Order can change SGD updates; reproducibility requires recording it.


## Calculation

updates = ceil(N/batch) × epochs regardless of permutation
