# Assessment architecture

Store original items with stable lesson IDs, solution and reasoning, difficulty and prerequisite references. Grade numerical items with stated tolerance; grade prediction before reveal; require a changed-input transfer task and debugging explanation. Chapter review mixes previous skills. Capstone rubric: data provenance/split, baseline, correct engine, reproducibility, evaluation, resource budget and limitations. All critical leakage/safety criteria must pass. Do not award mastery for clicks; persist attempt evidence only after schema/privacy review.
