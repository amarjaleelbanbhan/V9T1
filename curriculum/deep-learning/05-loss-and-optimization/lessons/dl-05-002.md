# Binary and categorical cross entropy


## Vocabulary

- **Target probability**: Probability assigned to the observed class.

- **Cross entropy**: Negative log probability of the target, averaged as specified.


## Meaning

For a binary target y, BCE = -y log(p) - (1-y) log(1-p). With p = 0.8 and y = 1, loss is -log(0.8). With y = 0 it is -log(0.2), a larger penalty. Categorical cross entropy for a one-hot target is -Σ yᵢlog(pᵢ), selecting the true-class probability. Natural logs are used here.


## Purpose

Confident wrong predictions deserve larger loss than uncertain wrong predictions.


## Calculation

BCE = -y log(p) - (1-y) log(1-p)


### Worked case

Inputs: [0.8, 1]. Result: 0.2231435513142097. Intermediate operations are available in the app.


### Transfer case

Inputs: [0.8, 0]. Result: 1.6094379124341003. Intermediate operations are available in the app.


## Explain

For a one-hot categorical target, which probability determines its loss?

The probability of the true class

The target selects the observed class; confident prediction of another class increases loss.


## Debug
