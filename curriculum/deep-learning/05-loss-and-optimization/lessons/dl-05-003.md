# Stable logits losses


## Vocabulary

- **Logit loss**: Cross entropy calculated directly from raw scores.

- **Log-sum-exp**: A stabilized log of a sum of exponentials.


## Meaning

A sigmoid followed by a naive logarithm can round a probability to zero or one. Compute BCE from logits using max(z,0) - zy + log(1 + exp(-abs(z))). This avoids exponentiating a huge positive z. For z = 1000 and wrong target zero, the loss is about 1000, not a NaN from log(0).


## Purpose

Stable objectives preserve useful values at confident predictions.


## Calculation

BCE(z,y) = max(z,0) - zy + log1p(exp(-abs(z)))
